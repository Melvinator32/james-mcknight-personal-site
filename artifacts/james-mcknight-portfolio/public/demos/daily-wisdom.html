How it works

Four rules the whole thing runs on.

Selection

Never-shown first

Every entry gets covered once before anything repeats. When a stream runs dry the cycle restarts from the oldest.

Size

One idea per entry

A title and a sentence or two. Long notes get split and prefixed by section so a set stays organized.

Sourcing

My words, not the book's

Copyrighted material is paraphrased on the way in. Verbatim is reserved for public-domain writers and my own notes.

Delivery

Once a day, catch-up safe

A scheduled task fires each morning and runs late if the machine was off. The send log guards against doubles.
